# Dashboard-Vendite-PowerBI-SQL
Dashboard per l'analisi delle vendite realizzata con Power BI e PostgreSQL. Il progetto analizza oltre 3.000 transazioni provenienti da 6 paesi, includendo visualizzazioni geografiche, trend temporali e analisi per categoria. Include script SQL completi per ETL, data cleaning e business insights con metriche su vendite, profitti e performance.
